# 84A 치수 도면 대조 — 2026-10-21

원본: `references/drawings/original/84a 평면도.pdf`.
도면명: 84㎡A형 단위세대 평면도(확장형), A02-102, 2025.10.
도면의 좌우는 현행 모델과 반대이므로 침실 표기와 인접 공간으로 대응했다.

## 확인 결과

**현행 모델은 도면 윤곽을 근사한 형상이며, 표기 치수를 모두 정확히 구속한 CAD 모델이 아니다.**
종전 모델에서 얻은 방 크기를 도면 확정 실내 치수로 사용하면 안 된다.

| 항목 | 도면 표기 | 현행 저장본 메시 | 차이 |
| --- | ---: | ---: | ---: |
| 침실2 가로 | 2700mm | 약 2710mm | +10mm |
| 침실3 가로 | 3000mm | 3018mm | +18mm |
| 침실2/3 사이 벽 | 65+65=130mm | 94mm | -36mm |
| 거실 가로 | 4500mm | 4537mm | +37mm |
| 안방 가로 | 3600mm | 3638mm | +38mm |
| 침실2 창 표기/모델 창틀 외곽 | 1700mm | 1710mm | +10mm |
| 침실3 창 표기/모델 창틀 외곽 | 2000mm | 2000mm | 동일 |

가로/벽 두께는 `assets/analysis/audit_plan_dimensions.py`로 저장된 실제 메시를
높이 1.5m·y=2.5m(안방 y=3.0m)에서 레이 검사했다. 창은 창틀 외곽 폭이다.
창 표기와 설치 개구부/창틀 제조치수는 별도이며 이 표의 일치만으로 시공 적합성을 뜻하지 않는다.
침실2 서쪽 벽은 추출 윤곽상 약간 기울어져 있어, 이전 꼭짓점 범위 계산값 2700mm와
중간 단면 실측값 2710mm가 다르다. 현재 방들이 완전한 직각 사각형이라는 보장도 없다.

## 깊이 해석 주의

도면의 2390+1450=3840mm는 서로 연결된 기준선 사이 치수다.
현재 실내 마감면 기준 깊이 약 3.39/3.37m와 직접 비교해 약 450mm 오차라고 단정할 수 없다.
확장부 외벽·창호·단열 마감과 북쪽 벽 두께를 같은 기준선에 맞춰 추가 대조해야 한다.
현재 남쪽 실내 면 y=.85는 Q10b/Q11에서 보완한 마감 가정이며 도면 수치로 확정한 값이 아니다.

## 이번 범위와 후속 작업

- 이번에는 위 대표 치수와 도면 기준선 해석을 확인했으며 Blender/웹 모델은 변경하지 않았다.
- 전체 문/창 위치·각 벽의 두께·방 깊이·단열 마감·천장고까지 전수 일치 검증한 상태가 아니다.
- 정확한 치수 모델로 정리하려면 기준축·벽체 두께·실내 마감선을 표기 치수로 재정렬하고,
  현행 가구와 기본장/문을 보존해 재배치한 뒤 기존 검사·충돌·GLB·렌더를 갱신해야 한다.
- 도면 원본과 읽기용 확대 이미지는 원본/파생 자료이며 `renders/`의 Blender 렌더와 구별한다.
