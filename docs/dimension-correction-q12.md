## 직접 표기가 없어 남긴 가정

- 알파룸 깊이 2280은 기준선/공유 벽 해석값이다. 세로 주석은 **1300+180+900**이며,
  2380 전체가 실내 깊이는 아니다. 끝점이 공유 벽 안에 있어 실내 깊이 확정 표기로 취급하지 않는다.
- 실외기실은 명시된 실내 깊이가 없다. 옆 PS 샤프트의 **1355를 방 깊이로 사용하지 않았다.**
  기존 트레이싱 형상을 보존해 폭 약 1525/깊이 1125로 직교화했다. 해당 치수는 잠정값이다.
  실외기 본체 길이 900은 줄이지 않고 유지했다. 실외기 형식·루버/설비 치수도 가정이다.
- 창호·문틀 상세, 비정형 샤프트의 작은 꺾임, 벽 마감 상세는 도면 형상 기반 근사다.
  명목 문 규격과 실제 유효 통과 폭은 다르다. 안방 발코니 미닫이 구조와 열린 상태를 보존했다.
- **사용자 확인 높이:** 일반 천장 2300, 거실 우물천장 안쪽 2400.
  천장 슬래브를 실제로 절개해 거실 안쪽을 100 높이고 사방 턱과 간접조명을 맞췄다.
  서재·유나방·안방 문 헤더는 명목 2200, 문짝 상부는 공제 후 2185로 조정했다.
- **높이 미해결:** 발코니 PD15×24의 명목 높이 2400은 바닥 레벨·천장/문 상부 상세 대조가 더 필요하다.
  현재 폭 1500과 미닫이 구조는 맞췄으나 기존 2150 헤더를 유지했다.
  낮은 바닥 구역의 FSD/WD ×22도 기존 프레임 높이를 유지했다. 이 높이들은 일치 완료가 아니다.
  도면 FL은 주 바닥 +120, 욕실/현관 +40, 발코니/실외기실 +70이다. 즉 주 바닥 대비 -80/-50이지만
  실제 마감 시공·천장 하부 높이는 미확정이다. 투어는 기존 평탄한 보행 바닥을 유지하고
  이 레벨차를 현행 모델 메타데이터에 기록했다. 사용자가 낮은 바닥 구역의 천장고가 다를 수 있음을 확인했다.

## 보존한 배치와 검증

1800×800/1400×700 책상, 검정·그레이 의자, 223개 장비 부품을 크기 그대로 이동했다.
유나방 북쪽 기본장, 낮은 침대·수납, 냉장고장 순서, 열린 중문과 안방 발코니 미닫이문도 유지했다.
팬트리 선반과 벽 마감은 바뀐 실내 면에 맞춰 조정했다. 공통 오크 바닥 UV는 유지했다.

- `verify_dimensions.py`: 실제 벽 레이/창 외곽/책상·문·천장·난간 높이 등 72개 검사.
  실외기실은 지정한 바닥뿐 아니라 별도 구조 벽면 사이 거리도 검사한다.
- Q5~Q11 검사 스크립트는 Q12 저장본에서 `verify_calibrated_rooms.py`의 방별 검사로 연결한다.
  이전 저장본에서는 기존 검사를 유지한다. 문·옵션·재질·통로·가구 치수 보존을 검사한다.
- `verify_master_balcony.py`: 플레이어 반경 280mm로 현관에서 24개 목표 지점까지 접근 가능.
  외창·외벽과 주차된 미닫이 패널은 이동을 막는다.
- 웹 테스트는 내보낸 GLB의 실제 삼각형 벽면을 다시 측정한다. 원본 테이블만 검사하지 않는다.

## 재현과 자료

교정 전 백업: `models/backups/apt_84a_photoreal_tour_before_dimensions.blend`.
`calibrate_dimensions.py`는 **항상 이 백업을 다시 연다.** Q12 이후 새 가구/수정을 한 다음에는
이 마이그레이션을 재실행하지 말고 현재 모델에 후속 수정을 적용해야 한다.
치수 정의는 `scripts/plan_dimensions.py`, 결과 표는 `assets/analysis/q12_dimensions.json`이다.

현재 전체 확인 이미지는 `renders/review/render_36_dimensioned_plan.png`다.
갤러리에 쓰는 기존 렌더는 `render_calibrated_gallery.py`로 Q12 저장본에서 갱신한다.
갱신하지 않은 과거 렌더/초기 계획의 좌표는 현행 치수 근거로 쓰지 않는다.
실측·시공 검증, 가전/문 전체 동작, 책상 승강 범위는 이번 검증 범위가 아니다.
