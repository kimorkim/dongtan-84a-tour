# Q12 全 세대 치수 교정 계획

기준은 `references/drawings/original/84a 평면도.pdf` A02-102 확장형이다.
현재 모델과 도면의 좌우는 반대이므로 방 이름/인접 관계로 대응한다.
좌표 원점은 유지하며 서쪽 안방 외곽 기준축 x=.35, 안방 발코니 남쪽 기준선 y=.35를 사용한다.

1. 도면의 연속 치수에서 기준축과 구조벽 면을 계산하고 표로 고정한다.
   전면 가로 축간 3845/4745/2900/3200mm, 내부 3600/4500/2700/3000mm와 벽 220/270/130mm를 함께 만족시킨다.
   북쪽 2175/1700/3580/2410mm와 내부 1970/1500/3400/2340mm, 중간 알파룸 2400·팬트리1190·현관1600mm를 구별한다.
2. 추출 윤곽의 기울기·짧은 모따기를 정리하고 구조/마감/개구부를 같은 기준선으로 보정한다.
   도면 바깥으로 연장됐던 현관 외곽을 제거하고 원래 앞문 개구부로 복구한다.
   주요 문/창 폭과 도면에 명시된 창턱·창 높이를 교정한다. 층고/실물 시공 상세와 웹의 바닥 단차 표현은 별도 가정으로 남긴다.
3. 가구·주방·기본 옵션·서재 장비·유나방을 보존한다. 기성품은 크기를 유지해 이동하고, 벽 맞춤 부재만 새 경계에 맞춘다.
   단일 오크 상면/UV를 유지하며 전체 바닥·천장은 실제 단위세대 외곽으로 닫는다.
4. 표기 치수에 대한 실제 메시 레이/외곽 검사, 기성품 크기 보존, 방별 통로와 현관부터 보행 검사를 실행한다.
   과거 좌표에 고정된 검사는 Q12 기준 좌표로 갱신하되 기존 재질·오브젝트 존재·메시 품질 검사는 유지한다.
5. 충돌/GLB·갤러리/확인 렌더·문서를 갱신하고 타입 검사·테스트·빌드와 실제 웹 표시를 확인한다.

기존 전체 생성 스크립트는 재실행하지 않는다. 적용 전 디스크 원본과 마지막 교정 상태를 별도 백업한다.
