# Q24 안방 욕실: 공식 84A e모델하우스 기준

사용자 요청: 안방 화장실을 e모델하우스 기반으로 제대로 만들고 문은 욕실 쪽으로 열리게 교정한다. 공식 `011_sphere` 6면과 거울장 열림 `011_1/011_2`를 자료로 확보했다. 이전 화장대(Q23c)는 보존한다.

## 확인한 오류

기존 `ProDoorLeaf_MasterBath`는 x2.124~2.570으로 파우더 방향에 돌출한다. `Master_Toilet_Bowl`은 y5.788부터여서 욕실 남쪽 실내 경계y5.970을 침범한다. `Master_Vanity_Top`은 구멍 없는 단순 상판이며 공식 사진의 벽걸이형 세면대와 다르다. 벽 마감·거울장·샤워/수건 부속도 사진과 불일치한다.

## 수정 범위

- Q12 구조 내측 x2.595~4.095/y5.970~8.170, 천장2300mm를 유지한다.
- 북쪽 욕조, 동쪽 벽의 벽걸이형 세면대와 그 남쪽 변기, 연속된 거울 슬라이딩 수납장/하부 얕은 선반을 공식 사진에 맞춘다. 세면대는 실제 볼이 파인 도기와 반다리/수전, 변기는 둥근 일체형 도기로 구현한다.
- 밝은 회색/베이지 벽300×600mm 가로배치, 바닥300×300mm와 별도 줄눈, 배수구·문턱·밝은 평천장/매입등/환기구를 추가한다. 타일 색·무늬는 공식 사진 깨끗한 부분을 참고하며 제조사 PBR 스캔이 아니다.
- 기존 문 개구부를 유지한다. 남쪽 힌지에서 +X 욕실 안으로85도 열린 문을 배치한다. 90도 끝에서는 손잡이가 남쪽 벽에 닿을 수 있어85도로 제한한다. 문짝과 손잡이는 같은 부모 변환으로 관리하고 문턱·틀과 기구 간격을 검사한다. 스윙 중 간섭도 기하학적으로 검사한다.
- 욕조 벽의 핸드샤워/슬라이드바/혼합수전/호스/선반, 반대편 수건봉·선반과 휴지걸이를 사진에 맞춘다. 사진에 없는 샤워부스/레인샤워는 추가하지 않는다.

## 가정과 완료 기준

기구 세부 규격·브랜드·타일 SKU·수납장 내부/배관은 사진만으로 확정하지 않는다. 제품 외형은 사진 기반 근사다. 도면 치수와 구조벽은 보존한다. 백업 후 부분 수정하고 독립 Blender 검사·기존19개 검사·실제GLB/충돌·욕실 출입/안쪽 보행·웹 테스트/타입/빌드 및 확인 렌더를 통과한다. 공식 사진과 새 렌더를 직접 대조한다. 웹 안방 욕실 갤러리와 관련 평면·파우더 확인 렌더도 갱신한다.
