# Q23 드레스룸 비우기와 파우더 화장대

Q23c 사용자 후속 요청: 형태는 유지하며 좌우 틈을 제거한다. 전체 가구를 실제 벽면에 맞춰 약1240mm 폭으로 늘리고 각 메시 정점에서 실제 벽을 측정해 0.5mm 마감선만 남긴다. 아래1100mm 폭은 이 요청으로 대체한다. 구조·깊이·상판높이·마감색은 유지한다.

## Q23b 사용자 사진에 따른 정정 — 아래 초안보다 우선

사용자는 초안이 일반적인 한국 아파트/푸르지오 일체형 파우더장과 다르다고 정정하고 사진3장을 제공했다. `references/furniture/powder-reference.md`가 최신 형태 근거다. 양옆 천장높이 상부장+큰 중앙 거울, 연속 상판과 가로2분할 얕은 무손잡이 서랍, 후퇴한 하부 양개장을 구현한다. 무릎 공간/기둥서랍/골드 장식은 폐기한다. 색은 사진의 적갈색이 아니라 현행 집의 밝은 그레이지/아이보리다. 위치와 폭1100/깊이450/상판750mm는 유지한다. 이 변경은 사용자의 사진 제공과 명시적 정정에 따른다.

사용자는 벽을 관통하는 드레스룸 가구를 정리하고 욕실 바로 앞 공간에 푸르지오 스타일 화장대를 요청했다. 밝은 그레이지 무광장·얇은 밝은 상판·직사각 거울·서랍·중앙 무릎 공간 및 기존 행거와 옷 제거 구성을 승인했다.

## 조사와 배치

현행 Dress_Closet_*는 y6.832~9.100을 차지하며 y7.100~7.200 구조 가벽을 관통한다. 부품별 Q12 좌표 보정 후에도 과거 연속 행거가 남은 문제다. 해당 조립체 전체와 Wardrobe_Dress_* 잔재만 제거하고 창·문·구조벽·바닥은 유지한다. 북쪽 드레스룸에 새 수납장은 추가하지 않는다.

욕실 문 맞은편 서쪽 벽 실내면 x=.485를 실제 메시 레이로 확인했다. 화장대 외곽은 x=.495~.945/y5.940~7.040, 상판 높이 .750m로 한다. 폭1100/깊이450mm. 전면은 +X. 중앙 무릎 공간 폭600mm 이상, 측면 서랍, 무광 그레이지 하부장과 밝은 상판, 직사각 거울을 배치한다. 의자는 추가하지 않아 동선을 비운다. 문짝의 현행 개방 상태와 간섭하지 않는다.

## 근거와 한계

공식 전시품목 페이지 https://www.prugio.com/hb/2025/dongtan/pages/display.asp?n=1 에서 드레스룸은 display84a_02임을 확인하고 원본을 references/modelhouse/original/에 저장했다. 이 사진은 시스템장 근거이며 화장대 제작도는 아니다. 사용자 승인한 화장대는 일반적인 붙박이형을 해석한 제안이며 정확한 푸르지오 옵션 복제품이라고 표기하지 않는다. 마감·서랍 분할·거울·조명 및 폭/깊이/높이는 가정이다. 수전·세면볼은 설치하지 않는다.

## 완료 기준

백업 후 현행 blend를 부분 수정한다. 구조 보존, 가구 제거, 실제 벽과의 비관통, 욕실 문 비간섭, 무릎 공간을 Blender에서 검사한다. 충돌/GLB를 갱신하고 욕실 앞·화장대 앞·드레스룸 내부 보행을 검사한다. 확인 렌더와 기존 드레스룸/전체평면 웹 갤러리, 자료 목록 및 품질 보고서를 갱신한다. 기존18개 모델 검사와 웹 테스트·타입 검사·빌드도 통과해야 한다.
