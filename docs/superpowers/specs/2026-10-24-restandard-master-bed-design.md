# Q22 안방 리스탠다드 킹 침대

**Q22c 후속 요청 우선:** 러그·협탁·탁상조명·협탁 위 펜던트를 제거한다.
침대 전체를22mm 내려 원목다리바닥z=0, 하단몸체z.115~.265/상단z.265~.555로 마루에 놓는다.
아래 러그/협탁 보존과 종전z좌표를 대체한다.

**Q22b 후속 요청 우선:** 사용자가 장식벽체 제거와 벽 밀착을 지정했다.
현재는 패널/띠조명을 제거하고 실제 서쪽 벽x=.485에 침대 머리를 붙인다.
중심x1.485/y3.2222, 외곽x.485~2.485다. 아래 초기 패널보존/옛x좌표만 대체하며 제품 규격은 유지한다.

사용자 지정 제품 1968, K 1600×2000mm. 사용자 확정 옵션은 헤드 없음과 115mm 원목다리다.
하단 그레이 몸체는 800×2000×150mm 두 개, 다리는 높이115/지름65mm다.
상단은 세트 기본 리스탠다드 독립 매트리스(제품818), 1600×2000×290mm로 모델링한다.
침대 자체 높이555mm. 원목다리는 기존 러그 상면 z=.022에 놓아 최상단 z=.577로 맞춘다.

기존 침대 중심 x=1.805/y=3.2222 및 서쪽 머리 방향을 유지한다.
침대 외곽 x=.805~2.805/y=2.4222~4.0222다. 하단2분할, 흰색 상단의 원형 퀼팅,
그레이 세로 봉제선, 파이핑, 원목다리와 제품 라벨을 사진 기반 근사로 표현한다.
기존 Bed_Master_*와 Q2_Master_Cushion*만 제거하고 벽 패널/러그/협탁/조명/구조를 보존한다.
제품 형태를 볼 수 있도록 기존 이불·러너·장식 쿠션은 새 침대에 옮기지 않는다.

원목다리가 보이는 115mm 구성을 사용자 승인안으로 채택했다. 14mm 저상형이나 헤드 추가형은
각각 다리 노출과 벽면 형상이 달라 이번 모델 대상에서 제외한다.

실측이 아닌 부분: 봉제 피치, 퀼팅 깊이, 다리 배치, 원단 반사율·색, 라벨 세부.
제조용 CAD나 수면 성능/하중 검증이 아니다. 출처는 references/furniture/60s-restandard/README.md.

검증: Blender 실물 메시 규격·바닥접촉·벽/협탁 비간섭·기존 방 보존, 독립 GLB 검사,
현관부터 안방/발코니 보행 회귀. 백업 뒤 수정하고 충돌·GLB·안방/전체평면 렌더와 웹 갤러리를 갱신한다.
원본은 기존 루트 blend. 이번 작업은 로컬 교체·확인 범위이며 별도 배포는 요청 시 진행한다.
