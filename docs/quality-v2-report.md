## 적용한 개선

### 전역 (`scripts/improve_quality_v2.py`, `v2b`, `v2c`)
- 잔존 기본광 비활성, 태양 단일화(4.5, 각도 2.5°), 포인트 에너지를 실측표로 재조정.

- 유리: Transmission(검게 읽힘) → 알파 0.15 Dithered로 교체. 창·다이닝 글라스 공통 해결.
