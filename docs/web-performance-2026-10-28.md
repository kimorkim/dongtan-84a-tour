# 디테일 유지 웹 성능 검증 (2026-10-28)

사용자 요청: 높은 모델 디테일을 유지하면서 웹 성능 개선.

## 변경

- 불투명 정적 메시를 재질·그림자 설정·천장 가시성·공간 셀별로 병합. 전체 메시1948개→423개.
- 삼각형529,316개를 모두 유지. UV·법선·재질·텍스처·조명·GTAO·출력 픽셀 비율 유지.
- 정적 모델의 로컬/월드 행렬을 고정하고 태양 그림자를 캐시. 걷기↔전체 보기에서 천장 표시가 바뀌면 그림자 재계산.
- Blender 원본·GLB·충돌 데이터·오프라인 렌더·갤러리는 변경하지 않았다.

## 동일 조건 전후 비교

Chromium headless, AMD Radeon 8060S / ANGLE D3D11, 1280×720 DPR1.
실제 GLB·조명·GTAO를 사용하는 고정 카메라4개. 12프레임 준비 후45프레임 실행.
CPU는 렌더 제출 함수의 벽시계 시간(드라이버 대기 포함), GPU는 타이머 쿼리 중앙값이다.
CPU/GPU 시간은 서로 겹치므로 합산하지 않는다. 프레임률은 평균 rAF 간격의 역수다.

| 시점 | 그리기 호출 전→후 | CPU ms 전→후 | GPU ms 전→후 | FPS 전→후 |
| --- | ---: | ---: | ---: | ---: |
| 현관 | 6276→605 | 12.7→3.1 | 15.87→5.71 | 60.0→60.0 |
| 거실 | 4503→251 | 14.3→2.0 | 15.02→3.38 | 58.7→60.0 |
| 안방 욕실 | 4737→303 | 19.0→2.2 | 17.12→3.41 | 46.3→60.0 |
| 전체 보기 | 9504→1220 | 29.4→5.6 | 27.66→4.72 | 32.2→60.0 |

그리기 호출은 색상·AO·그림자·후처리 전체를 합산했다. 60Hz 제한으로 여유 성능이 FPS에 전부 나타나지는 않는다.
이 수치는 해당 기기의 짧은 고정 카메라 측정이며 모든 기기·해상도·이동 경로의 FPS를 보장하지 않는다.
원본 GLB 다운로드 용량/초기 디코딩 속도를 줄이는 작업은 포함하지 않았다.

## 형상·화면·동작 검증

- 기존 GLB 검사11개와 신규 병합 검사3개, 총14개 통과. 타입 검사와 프로덕션 빌드 통과.
- 신규 검사는 부모 회전·이동이 있는 메시의 월드 정점·법선·UV·삼각형 수 보존,
  천장 분리·공간 셀 분리·투명 메시·다중 재질·음수 스케일 보존을 검증한다.
- 전후4개 화면의 평균 채널 차이0.11~0.37/255. 채널 차이8을 넘는 픽셀은 각 화면의0.16~0.93%.
  AO 노이즈와 병합에 따른 래스터/그림자 차이가 있으므로 픽셀 단위 완전 동일을 주장하지 않는다.
  거실·욕실·전체 보기 화면을 직접 확인했다.
- 실제 메인 화면1280×720 DPR2에서 걷기→전체 보기→걷기, 키보드 이동, 위치 초기화 확인.
  천장·그림자 복원 후 최초 걷기 화면과 채널 차이0. JavaScript 예외0개.
