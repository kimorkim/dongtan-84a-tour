## 배치·해석 범위

Q22b에서 침대 중심을 x1.485/y3.2222로 옮기고 서쪽 머리 방향을 유지했다.
외곽 x.485~2.485/y2.4222~4.0222, 다리바닥 z=0, 하단몸체 z.115~.265,
상단 z.265~.555. 사용자 요청으로 연출용 벽 패널·위아래 띠조명을 제거하고
실제 서쪽 구조벽 실내면x=.485에 침대 머리 쪽을 밀착했다.
Q22c에서 러그·협탁·대리석 상판·탁상조명·협탁 위 펜던트도 제거하고 침대를22mm 내려 마루에 직접 놓았다.
제품 형상을 볼 수 있도록 이불·러너·장식쿠션과 옛 헤드보드는 제거했다.

봉제·퀼팅 피치/깊이, 원단색·목재결, 손잡이·라벨과 다리 위치는 사진 기반 근사다.
생성된 `assets/textures_export/q22_{grey,white,wood}.png`는 코드로 만든 원단/목재 표현이며 제조사 PBR 스캔이 아니다.
실제 하중, 매트리스 탄성, 다리 구조 강도와 제작 적합성은 검증하지 않았다.
남쪽 기존 미닫이문 벽과 침대 사이 공간은 성인 보행 통로로 검증하지 않는다.
