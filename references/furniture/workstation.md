# Q11b 서재 장비 참고와 가정

2026-10-21 사용자 지정: 큰 책상에 모니터암을 쓰는 Dell 27인치 2대, 세로 스탠드의 닫힌 맥북,
키보드/마우스, Audioengine A2 스피커 2대. 작은 책상에는 모니터 받침대 위 32인치 게이밍
모니터와 키보드/마우스, 아래에는 데스크톱 본체. 두 의자는 상판 아래로 더 밀어 넣는다.

- Audioengine 공식 A2 치수: 한 대 H152.4×W101.6×D133.35mm.
  https://audioengineeu.com/support/a2-weights-and-measures/
  2웨이 드라이버와 전면 하단 슬롯 포트를 가진 검정 캐비닛으로 재현했다.
  드라이버/포트/단자 상세 치수와 검정 색상은 외형 근사다.
- Dell 27인치 참고: https://www.dell.com/en-gb/shop/dell-27-plus-qhd-usb-c-monitor-s2722dc/apd/210-bbrr/monitors-monitor-accessories
  정확한 사용자 모델 미지정. 16:9 활성화면 대각 685.8mm, 얇은 검정 베젤/뒤 VESA/델 표기 형상으로 재현한다.
  특정 Dell 모델과 동일한 제조사 CAD가 아니다. 상판 뒤쪽 클램프형 독립 암 2개를 사용한다.
- 32인치 게이밍 모니터는 브랜드/모델 미지정. 평면 16:9 활성화면 대각 812.8mm와 일반 스탠드,
  높이 120mm/폭 820mm 받침대로 재현했다. 곡률/실제 제품 규격은 미확정이다.
- 맥북은 모델/색 미지정으로 16×221×312mm 닫힌 실버 외형을 세워 두었다.
  스탠드와 케이블은 배치 검토용 근사이고 실제 USB-C 연결/전원/발열 성능 검증이 아니다.
- 작은 책상 본체는 W190×D400×H450mm 가정이다. 북쪽 다리 안쪽·의자 바퀴 바깥에 둔다.
- 큰 의자 중심은 동쪽으로 220mm, 작은 의자는 270mm 이동했다.
  좌판 일부가 상판 아래에 들어가며 팔걸이는 상판 아래, 등받이는 상판 앞을 유지한다.
- 화면은 꺼진 상태다. 실제 승강 범위, 모니터암 허용 하중, 가전 발열/배선/콘센트는 별도 검증 대상이다.
