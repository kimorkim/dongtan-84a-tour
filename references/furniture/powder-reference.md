# Q23b 사용자 지정 아파트 일체형 파우더장

Q23c 후속 요청: 좌우에 공간 없이 실제 벽에 밀착한다. 아래1100mm는 이전 가구 폭이며 현행은 벽면에 따라 약1235~1249mm다. 실제 구조벽을 유지하고 각 깊이 위치에서 좌우 끝을 맞추어 약0.5mm 마감선만 남긴다.

사용자는 첫 제안이 푸르지오 아파트에 흔한 화장대 형태가 아니라고 정정하고 아래 사진3장을 제공했다. 형태는 이 사진을 우선하며, 사진의 적갈색 마감은 원하지 않는다고 명시했다.

두 캡처에는 117㎡ 표시가 있다. 현 프로젝트84A 실물/정확한 옵션 제작도라고 해석하지 않는다. 사진 속 파우더장의 유형·비례·수납 구성을 현재 욕실 맞은편 벽에 맞게 해석한다.

현재 집의 마감에 맞춰 하부는 밝은 그레이지, 상부는 밝은 아이보리, 상판은 따뜻한 백색으로 한다. 중앙 무릎 공간·양옆 서랍 기둥·골드 바 손잡이·액자형 거울·상부 장식조명을 제거한다. 하부 양개장 전면은 상판보다 약90mm 물리고 위에 얕은 서랍2개를 연속 배치한다. 거울은 양옆 상부장 사이를 크게 채우며 전체 상부는 2300mm 천장 아래까지 닫는다.

폭1100/깊이450/상판750/상부2299mm는 현재 공간에 맞춘 모델 치수다. 사용자가 제공한 사진만으로 브랜드의 정확한 제작 규격·경첩·내부 구성·재질을 확정하지 않는다. 문/서랍은 닫힌 정지 상태이며 개폐 중 간섭은 미검증이다.
